# WordPress & Elementor Import Guide for Kristian Mesa SEO Portfolio

This guide explains step-by-step how to import Kristian Mesa's SEO Portfolio into any WordPress website using **Elementor** (Free or Pro version).

---

## Method 1: Import Native Elementor Template (Recommended - 1 Click)

### Prerequisites:
- WordPress website installed.
- **Elementor** plugin installed and activated (Plugins > Add New > Search "Elementor").

### Step 1: Download the Template JSON
Download the [`elementor-template.json`](file:///C:/Users/ADMIN/.gemini/antigravity-ide/scratch/kristian-mesa-seo-portfolio/elementor-template.json) file from this portfolio repository or click the **Export Elementor Template** button on the web app.

### Step 2: Upload to WordPress
1. Log into your **WordPress Dashboard** (`yourdomain.com/wp-admin`).
2. Go to **Templates** > **Saved Templates** in the left sidebar menu.
3. Click the **Import Templates** button at the very top of the page.
4. Click **Choose File**, select `kristian-mesa-portfolio-elementor.json`, and click **Import Now**.

### Step 3: Insert into Any Page
1. Create or edit a page (e.g. **Pages > Add New** -> title it "Portfolio" or "SEO Specialist").
2. Click **Edit with Elementor**.
3. In the Elementor canvas, click the **Folder Icon** ("Add Template").
4. Go to the **My Templates** tab.
5. Locate **Kristian Mesa - SEO Specialist Portfolio Template** and click **Insert**.
6. Click **Publish** at the bottom left!

## Method 2: Embed Complete Web Portfolio via HTML / Code Block (Elementor Free/Pro)

If you want the exact styling, animations, interactive local audit tool, and smooth dark-theme effects from the full web app:

1. Open any page in **Elementor**.
2. Drag an **HTML Widget** into your section.
3. Open [`index.html`](file:///C:/Users/ADMIN/.gemini/antigravity-ide/scratch/kristian-mesa-seo-portfolio/index.html) and copy the content inside `<body>...</body>`.
4. Paste the content into the Elementor HTML widget box.
5. In the same page or in your theme's custom CSS setting (**Appearance > Customize > Additional CSS**), paste the contents of [`styles.css`](file:///C:/Users/ADMIN/.gemini/antigravity-ide/scratch/kristian-mesa-seo-portfolio/styles.css).
6. Save and publish!
